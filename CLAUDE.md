## Token rules (strict)
- Session start: read ONLY `.claude/session-handoff.md` and `docs/repo-map.md`. Never scan the repo.
- Locate code with `Grep "<symbol>" docs/code-index.md` (auto-generated, never Read it whole), then Read the file by line range.
- Never Read a file over 300 lines whole. Never regenerate unchanged content. Targeted edits only.
- Do not use conversation_search or re-read old chats for context: repo-map + handoff are the memory.

## Edit rules (strict)
- Never rewrite or reformat a whole file. No refactors, renames or style changes unless asked.
- Before editing: state in one line what you touch. Preserve every feature, public name and BrandConfig key.
- After editing: run `./gradlew testDebugUnitTest assembleDebug`, update `docs/repo-map.md` (2 lines), commit with a clear message.
- Change > 150 lines: propose a plan first. Never remove or change a feature without approval.
- Never reintroduce a bug listed under "Solved bugs" in `docs/repo-map.md`.

## Workflow
- Feature request: plan, wait for approval, implement on branch `feature/<name>`.
- New project: static prototype first (home screen, 3 directions, sample data, no logic), stop for my choice. Never rebuild the shell after approval.
- Logo / brand mark / app icon: load skill `logo-design` first. Any UI or screen: load skill `design-system` first.
- Session end: rewrite `.claude/session-handoff.md` (max 25 lines): state, decisions, open issues, next step.
- Version: bump VERSION_NAME in gradle.properties + version.json on substantive changes. Release notes in `docs/releases/vX.Y.Z.md` (الإضافات / المميزات / الإصلاحات).
- `docs/code-index.md` is generated by `.github/workflows/repomap.yml` on every push. Never edit it by hand.

## Stack
- Native Android: Kotlin + Jetpack Compose, minSdk 26, compileSdk 36, targetSdk 36. Hilt + KSP, kotlinx.serialization. No WebView, no WebToApp.
- APK built, signed and released by GitHub Actions (`build.yml`); zip uploads are unpacked by `unpack-zip.yml`.
- Offline first: every network call in try/catch with a graceful fallback. Cloud only when sync is needed: Firebase Auth + Firestore + Cloudflare Worker; Security Rules enforce access, client checks are cosmetic.

## Architecture
- `BrandConfig.kt` is the only place for brand name, OKLCH palette, currency and tunables. New client = edit BrandConfig only.
- Room with numbered migrations (append only). Balances are derived from append-only transactions; deletes are soft.
- Each module is a schema object rendered by one generic engine.

## Design and security
- Icons: hand-drawn vectors in one Icons file. No emoji, no icon packs.
- Contrast >= 4.5:1, touch targets >= 44dp, visible focus, respect "remove animations". Numbers inside Arabic text go through an LTR isolate.
- Sanitize all input. Never put secrets in code, logs, commits or release notes.

## Code hygiene
- No comments revealing AI authorship. Comments only when necessary, short Arabic. No dead code, no TODOs.
